👋 你好，我是云云

大家好，我是 云云，也叫 云帆，一名有趣的互联网人。我深耕AI应用开发多年，从最初的传统开发到如今All in AI，擅长利用各类AI工具打造自动化工作流，独立开发完整AI产品，这一路走来充满了挑战与收获。

🛠️ 我做了什么

我独立开发了 云云的AI工具箱（tool.itmagical.top），这是一个包含 42款免费在线工具 的平台，涵盖图片处理、文档转换、音视频编辑、编码转换、设计创作等六大类。所有工具均在浏览器中运行，无需下载安装，数据处理在本地完成，保障用户隐私安全。

主要工具包括：智能抠图、图片压缩、图片OCR识别、PDF工具集、视频处理、Markdown编辑器、二维码生成、思维导图、小红书封面设计等。平台月活用户已超过 50K+。

💡 我的AI能力

熟练掌握 Prompt Engineering（提示词工程），擅长使用 Cursor / Windsurf / Copilot 等AI编程助手进行高效开发。精通 GPT-4o / Claude / Gemini / 豆包 等主流大模型的应用与调优。擅长用 Coze / Dify / n8n 搭建AI自动化工作流，利用 ComfyUI / Midjourney / Stable Diffusion 进行AI图像生成，并能使用 剪映 / Runway / Suno 等AI工具完成视频与音乐创作。
